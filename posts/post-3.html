用纯静态页面搭一个能跑的博客

2026-09-20 · 教程

很多人以为做博客一定要上框架、配构建、连数据库。其实一个能长期稳定运行的博客，往往越简单越好。这篇就讲讲这个博客本身是怎么搭的。

目录结构

github-io-blog/
├── index.html        # 首页（文章列表）
├── about.html        # 关于页
├── posts/            # 每篇文章一个 HTML
│   ├── post-1.html
│   ├── post-2.html
│   └── post-3.html
├── assets/
│   ├── css/style.css
│   └── js/main.js
└── README.md         # 部署说明

新写一篇文章

复制 posts/post-1.html，改标题、日期和内容，再到 index.html 里加一张卡片链接过去，就完成了。没有编译，没有依赖。

部署到 GitHub Pages

  1. 在 GitHub 新建仓库，名字必须是 Tiantiankaixin6666.github.io。
  2. 把整个文件夹的内容推上去：git add . && git commit && git push。
  3. 等一两分钟，打开 https://tiantiankaixin6666.github.io 就能看到。
维护成本为零的博客，才更可能活得久。

这就是全部。不需要 Node，不需要 Hugo，不需要每月续费服务器。写就完事了。
