我如何理解 CSS 变量与暗色模式

2026-09-10 · 前端

暗色模式听起来高级，做起来其实就三件事：定义变量、切换属性、记住选择。

1. 用变量统一颜色

把所有颜色抽到 :root 里，页面里只引用变量名。切换主题时，只要改 data-theme 这一个属性即可。

:root {
  --bg: #ffffff;
  --text: #1a1a2e;
}
[data-theme="dark"] {
  --bg: #0f172a;
  --text: #e2e8f0;
}

2. 一行 JS 切换并记忆

读取本地存储，没有就跟随系统；点按钮时切换属性并存回 localStorage。

var theme = localStorage.getItem("theme")
  || (matchMedia("(prefers-color-scheme: dark)").matches ? "dark" : "light");
document.documentElement.setAttribute("data-theme", theme);

3. 别忘了过渡

给 body 加上 transition: background .3s, color .3s，切换时才有顺滑的淡入淡出，而不是硬切。

主题切换的本质，是一次性的属性替换，不是一堆 if/else。

就这么简单。本博客的右上角按钮，就是按这个思路实现的，你可以打开源码对照看。
